# 使用指南

[English](usage.md) · [README](../README.zh-CN.md)

## 语言与工作区

顶部选择 **EN** 或 **中文**。语言偏好在当前浏览器刷新后保留，不会修改机器人设置。左侧导航跳转到驾驶、建图与设备区域。窄屏会纵向排列各面板，顶部停车按钮始终可用。

## 手动驾驶

1. 确认摄像头正在显示新画面、底盘在线，并释放实体暂停按钮。
2. 设置前进、后退和转向上限，点击**保存速度上限**。保存时会停车并锁定驾驶，设置保存在机器人上。
3. 点击**启用手动驾驶**。
4. 按住网页方向按钮或键盘按键；松开会发送零速度。前进/后退可以与转向组合。
5. 点击**停车并锁定**、顶部**停车**，或按**空格键**，即可停车并锁定驾驶。

| 输入 | 动作 |
| --- | --- |
| W / ↑ | 前进 |
| S / ↓ | 后退 |
| A / ← | 左转 |
| D / → | 右转 |
| 空格 | 停车并锁定 |

编辑输入框时忽略方向快捷键，空格仍用于停车。页面隐藏、窗口失去焦点、相机画面过期或连接中断都会结束驾驶。另一个标签页不会继承当前页的驾驶启用状态，而会提示其他页面正在控制；停车按钮可以终止该控制。

### 速度上限

前进和后退分别接受 0–1.00 m/s，转向接受 0–2.00 rad/s，左右共用。设为零会禁用对应运动分量。默认前进 0.10 m/s、后退 0.05 m/s、转向 0.30 rad/s。1 rad/s 约为每秒 57 度。

这些数值是指令上限。实际速度受底盘、轮胎抓地、转向模式、电量影响。运行数据展示的是里程计测得的速度，不是设定值。自动导航采用独立配置，不会随手动速度上调而加速。

手动驾驶不会用雷达自动避障。请自行观察环境，后退前确认后方空间；摄像头视野有限。

## 建图与导出

1. 保持雷达扫描开启。
2. 在开始任务前选择 Cartographer 或 SLAM Toolbox。
3. 点击**开始建图**。机器人先停车，再启动 SLAM，不会下达运动目标。
4. 地图出现后启用手动驾驶，巡视周围空间，相机与地图会实时更新。
5. 可输入名称（1–64 个英文字母、数字、下划线或短横线），再点击**保存地图**；留空则生成带时间戳的名称。保存会停车，但 SLAM 继续运行。
6. 选择已保存的地图，点击**下载地图 ZIP**。压缩包包含 `.pgm` 和 `.yaml`，YAML 内图像路径为相对路径，可一起移到其他目录。
7. **保存并结束**会先保存当前的新鲜地图，再结束建图。如果保存失败，会保留 SLAM 任务以便重试。已有地图名称不会被覆盖。

地图默认只用于显示。只有明确启用点击导航后，点击地图才可能驱动机器人。地图区分已知空地、障碍与未知区域；箭头表示机器人估计位置。重启建图可能建立新的 SLAM 任务，切换引擎或关闭服务前应保存重要地图。

## 暂停与恢复雷达

**暂停扫描数据**会先停车，调用 `/stop_scan`，并等待数据停止。**恢复扫描数据**调用 `/start_scan`，等待新扫描到达。偏好在控制服务重启后保留，驱动失败或超时会显示错误，而不会报告未经确认的成功。

此功能控制数据采集，不验证物理旋转；在已测试硬件上，它不能让电机停转。建图与导航需要新鲜扫描；暂停扫描时，相机辅助的手动驾驶仍可能可用。恢复扫描不会自动恢复先前的驾驶任务。

## 可选自动导航

在地图面板展开**自动导航与探索**，点击**启用自动导航**，等待 Nav2 与定位就绪。自动任务需要四轮差速模式，以及新鲜的底盘、相机、雷达和地图数据。

- **地图目标：**勾选允许点击地图下达行驶目标，再点击已知空地。系统按车身轮廓检查目标，此操作会使机器人行驶。
- **自动探索：**通过 Nav2 选择可达的未知区域边缘；每轮最多两分钟、六米或十二个到达目标。随时可停车。
- **沿原路返回：**按当前任务记录的里程计轨迹返回起点。自动模式仅在后方雷达确认净空时倒车，否则转向后前进。这是当前会话路线，不是持久保存的全局“家”。

狭窄区域无法找到路线时，探索可能进行雷达检查后的直行补图：以 0.035 m/s 缓慢前进，到约 2.5 cm、三秒截止时间或通路净空不足时停车；等待 2.5 秒后重新规划。等待是让地图更新的缓冲时间，不代表已经确认地图版本发生变化。最多尝试六次。反复出现补图提示说明规划困难，不代表应提高手动速度。

## 故障排查

| 现象 | 检查与处理 |
| --- | --- |
| 网页无法连接 | 保持 SSH 隧道运行；在机器人环境检查 `manage.sh status` 和 `curl http://127.0.0.1:8765/status`。 |
| 无法启用驾驶 | 检查相机画面是否新鲜、底盘状态、指令控制模式、实体暂停按钮，以及设备/建图操作是否完成。 |
| 转向速度受限 | 在速度上限中修改**转向**、保存并重新启用驾驶，核对已生效数值。手动设置不改变 Nav2 上限。 |
| 相机太暗或过曝 | 检查照明与 `bringup.launch.py` 中设备支持的参数，包括自动曝光、增益、伽马和防闪烁频率。 |
| 雷达恢复后没有数据 | 检查供电、串口和驱动服务。暂停不应结束提供恢复服务的驱动进程。 |
| 暂停后雷达仍有噪声 | 数据暂停不会让电机停转，界面也无法验证物理旋转。 |
| 地图不出现 | 检查 `/scan`、`/map`、`map → odom → base_link` 变换和建图日志。启动最多等待约 25 秒；修复原因后重试。 |
| 地图保存失败 | 检查磁盘空间、写权限和地图数据是否新鲜；名称已存在时请换名。 |
| 自动探索反复停止 | 未知区域、狭窄通道、扫描覆盖不足或障碍可能使路线不可行，可继续手动建图补全环境。 |
| 高级桌面打不开 | 安装可选桌面工具，确认本地 16080 端口已转发；这不影响主控制台。 |

公开提交问题前，请检查日志、相机图像、地图、主机名和连接信息，避免附带私有数据。
